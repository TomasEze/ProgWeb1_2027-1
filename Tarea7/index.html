Resumen HTML: Conceptos y etiquetas

Esta página va a resumir los principales conceptos y etiquetas vistas en la clase de Programación Web 1, en el módulo HTML

Conceptos principales HTML

HTML

Es un lenguaje demarcado de hipertexto, es un lenguaje de marcas para estructurar sitios web

Elemento HTML

Un Elemento HTML es la unidad básica de estructura y contenido en una página web, y está compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <head>

Es una etiqueta que se utiliza para comunicarse con el navegador a través de los metadatos, permite mejorar el SEO, además se enlaza archivos externos de estilos o scripts

Etiqueta <body>

Dentro de esta etiquetava todo el contenido que ve el usuario en nuestra página web

Contenedores semánticos

<header> Es una etiqueta utilizada para el contenido introductorio de una página web, puede contener el logo, menú de navegación principal, el nombre de la empresa, etc
<nav> Etiqueta utilizada para el menú de navegación principal, suele contener enlaces a otras páginas relacionadas o navegar por la página principal, no debe haber más de 1 en la página
<main> Etiqueta única de una página web cuyo propósito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocará el contenido principal de nuestra página
<section> Etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para dividir a una página web en secciones y agrupar contenido relacionado
<article> Es una etiqueta que se utiliza para grupar contenido autónomo que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<footer> Es una etiqueta que normalmente se encuentra hasta el final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria
<aside> Esta etiqueta representa una sección de la página web cuyo contenido no está directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros artículos relacionados, etc

Elementos principales de HTML

Elemento <a>

Este elemto contiene enlaces a otras páginas

  • Externos
  • Internos
  • De ancla/anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/0123456789"
Este valor envia un whatsapp a un número específico
href="mailto:example@gmail.com"
Envía un correo a un mail específico

Elemento <form>

Es la manera en que los usuarios se pueden comunicar con una página web, gracias a este elemento se pueden procesar datos de los usuarios según el objetivo de nuestra página web
